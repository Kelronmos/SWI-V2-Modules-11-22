# Claim → Operation Registry

**Doctrine:** DOCUMENT ≠ PROOF. DOCUMENT → REQUIREMENT.

```
DOCUMENT CLAIM → OPERATIONAL CONTRACT → IMPLEMENTATION → TEST → CI → SEAL
```

## Roles
| Artifact | Role |
|----------|------|
| PDF / historical doc | Requirements / history corpus |
| Operational contract | Executable spec (input → rule → output → tests) |
| Code | Implementation |
| Test | Behavioural evidence |
| CI | Reproducibility |
| Seal | Integrity / continuity of a defined boundary |

## Forbidden loop
PDF says it exists → declared implemented.
Required: PDF → contract → code satisfies → tests → CI.

## Sequencing
M11 first (V2 verification target). M00–M10 next (V1). M12–M46 only after contracts exist.
