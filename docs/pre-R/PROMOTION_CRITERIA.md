# pre-R Promotion Criteria (V2)

Do not promote because code exists.

Require: frozen contract · complete implementation for scope · no known bypass · no hidden V1 dependency · unit/integration/adversarial/property/cross-layer tests · tip CI evidence · limitations + claim-language review · **explicit AUTHORIZED to promote**.

```text
DESIGNED → IMPLEMENTED → UNIT → INTEGRATION → CI
  → ADVERSARIAL → AUDITED → AUTHORIZED → SEALED
```

Insufficient alone: unit pass, signature OK, hash OK, UI looks right, one integration test, CI green, certificate exists.
